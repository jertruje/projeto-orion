# Matriz inicial de métricas

Não há benchmark de desempenho do ORION OS medido. “Meta” abaixo é protocolo
para estabelecer baseline, não número inventado nem aprovação já atingida.
Quando não há um componente executável, resultado é **não medido / não
aplicável ao scaffold**.

## Protocolo de estabelecimento de baseline

1. Fixar commit, compiler/linker versions, opções, artefatos, firmware, QEMU
   version, máquina/vCPU/RAM, host OS e política de cache.
2. Definir workload e critérios de correção antes de coletar números.
3. Fazer warm-up quando aplicável; registrar número de amostras, mediana,
   percentis, variância e outliers, preservando dados brutos.
4. Repetir em execução independente; separar resultado QEMU/TCG de hardware.
5. Não converter uma meta relativa em alegação se o baseline não é comparável.

## Valores conhecidos do scaffold

O teste atual valida sequência de boot por mensagens; não mede latência de
boot com clock calibrado. Métricas de scheduler, IPC, memória, isolamento,
recuperação, drivers e aplicações continuam não medidas.
